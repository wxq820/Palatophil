## 四、当前需求基线（V1.2 摘要）

### 4.1 业务范围
- 智能备菜点餐系统（微信小程序）
- 双栏烹饪页：左标准配方，右实时计算
- K 系数换算食材重量
- 食谱多版本派生
- 家庭多人协作点餐（≤ 20 人）
- 自动合并采购清单

### 4.2 技术栈
- 后端：Java 17 + Spring Boot 3.x + MyBatis-Plus 3.5+
- 数据库：MySQL 8.0
- 小程序：微信原生（WXML / WXSS / JS）
- PC 后台：Vue 3 + Element Plus
- 通信：RESTful API + WebSocket

### 4.3 关键约束
- 底层食材量统一以"克"存储，保留 1 位小数
- < 0.1g 不展示；≥ 0 但 < 0.1g 显示 0.1g
- 配方必须 ≥ 1 主料 + ≥ 1 辅料
- 单会话 WebSocket 在线 ≤ 20
- 私有食谱直接删；公开食谱注销后转为原作者孤儿食谱
- 历史合并单只读归档
